# 機車排氣定期檢驗資訊專區｜Q版圖片更換版

這份檔案是依目前 https://yun2668.github.io/888/ 的版面製作。

## 最簡單更新方式
只要把 GitHub 儲存庫 `888` 裡的 `index.html` 替換成這份新版即可。
原本的 `style.css`、`script.js` 不用更改。

## 已更換
1. 首頁「機車檢驗線示意照片」→ Q版車主＋機車＋定檢站插畫
2. 「為什麼機車要做排氣定檢？」照片 → Q版排氣檢測＋清新空氣插畫
3. 移除 Wikimedia 照片授權說明，改成本站 Q 版插圖說明

## 圖片顯示方式
兩張圖已用 Data URI 直接內嵌在 index.html。
因此：
- 不需要 images 資料夾
- 不需要 assets 資料夾
- 不會因外部圖片網址失效而消失

另外也附上 2 張獨立 SVG，方便日後另作使用。
